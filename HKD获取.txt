## HKAB 汇率 API 调用方案

### 🔍 API 发现过程

我用 Playwright 浏览器打开 HKAB 页面后，拦截了页面的网络请求。当日期选择器切换到某个日期时，页面发了一个 AJAX 请求：

```
GET https://www.hkab.org.hk/api/member/public/getExrate/2022-01-03
```

这个 API **纯公开、无鉴权**，直接 GET 就能拿到 JSON。

### 📡 API 详情

**端点格式**：
```
GET https://www.hkab.org.hk/api/member/public/getExrate/{YYYY-MM-DD}
```

**示例**：
```
https://www.hkab.org.hk/api/member/public/getExrate/2022-01-03
```

**返回 JSON 结构**（关键字段）：
```json
{
  "soFar": null,
  "lastRate": {
    "date": "2022-01-03",
    "USDSelling": "7.7980",
    "USDBuyingTT": "7.7930",
    "USDBuyingOD": "7.7900",
    "CNYSelling": "1.2245",
    "CNYBuyingTT": "1.2195",
    "CNYBuyingOD": "1.2150",
    "GBPSelling": "10.5020",
    "GBPBuyingTT": "10.4620",
    "GBPBuyingOD": "10.4220",
    ...
    "holiday": "0"
  }
}
```

**字段命名规则**：
- 卖出价：`{货币代码}Selling`
- 电汇买入：`{货币代码}BuyingTT`
- 汇票买入：`{货币代码}BuyingOD`
- `holiday`：`"0"` = 交易日，非 `"0"` = 假日

### 🐍 Python 调用代码

```python
import requests
import json

# 单日查询
date_str = "2022-01-03"
url = f"https://www.hkab.org.hk/api/member/public/getExrate/{date_str}"
resp = requests.get(url)
data = resp.json()

# 汇率数据在 lastRate 里
rates = data.get("lastRate", {})
print(f"日期: {rates.get('date')}")
print(f"USD 卖出价: {rates.get('USDSelling')}")
print(f"CNY 卖出价: {rates.get('CNYSelling')}")
print(f"是否假日: {rates.get('holiday')}")
```

### ⚙️ 完整批量抓取逻辑

```python
import requests
import csv
from datetime import datetime, timedelta

start = datetime(2022, 1, 1)
end = datetime(2026, 6, 10)
current = start
records = []

while current <= end:
    date_str = current.strftime("%Y-%m-%d")
    url = f"https://www.hkab.org.hk/api/member/public/getExrate/{date_str}"
    
    try:
        resp = requests.get(url, timeout=30)
        data = resp.json()
        rates = data.get("lastRate", {})
        
        # 跳过假日
        if rates.get("holiday") != "0":
            current += timedelta(days=1)
            continue
        
        # 提取每种货币
        for code, name in CURRENCIES:
            sell = rates.get(f"{code}Selling", "")
            buy_tt = rates.get(f"{code}BuyingTT", "")
            buy_dd = rates.get(f"{code}BuyingOD", "")
            unit = "1" if code == "GBP" else "100"
            
            records.append([date_str, code, name, unit, sell, buy_tt, buy_dd])
        
    except Exception as e:
        print(f"失败 {date_str}: {e}")
    
    current += timedelta(days=1)

# 写入 CSV
with open("hkd_rates.csv", "w", newline="", encoding="utf-8-sig") as f:
    w = csv.writer(f)
    w.writerow(["Date", "Currency_Code", "Currency", "Unit", "Selling", "Buying_TT", "Buying_DD"])
    w.writerows(records)
```
